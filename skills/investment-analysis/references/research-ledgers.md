# 研究控制账本

招股书 full analysis 必须在写报告和 slides 前建立以下四个文件。它们不是附录装饰，而是防止数字、实体、融资和展示口径漂移的研究控制件。

## 1. evidence_ledger.md

逐项记录会进入正文、模型或 slides 的关键事实。至少包含：

| claim_id | 模块 | 事实/数字 | 期间 | 单位 | 来源文件 | 页码/章节 | 原文或表名 | 提取/计算 | 置信度 | 使用位置 |
|---|---|---|---|---|---|---|---|---|---|---|

规则：

- 财务、经营 KPI、客户/供应商、竞对、融资、股权和老股交易均要有 claim_id。
- PDF 页码优先写文件印刷页码，同时记录 PDF 物理页码或章节，避免版本变化后找不到。
- “提取”与“计算”分开；计算项注明公式和输入 claim_id。
- 同一数字口径冲突时并列记录，不静默覆盖；在备注写最终采用原因。

## 2. entity_map.md

统一匿名实体、SPV、基金主体和集团品牌。至少包含：

| raw_name | disclosure_code | display_name | parent/brand | type | evidence | confidence | aliases | notes |
|---|---|---|---|---|---|---|---|---|

规则：

- `raw_name` 保留招股书法律主体原文；`display_name` 是报告/slides 统一展示名。
- 机构、主机厂、CVC、客户、供应商、竞对和员工平台都纳入；不得只维护匿名公司。
- 当前持有人、原始认购人、领投方、老股买方/卖方是不同角色，不能因同属一个集团而混为一列。
- 高置信结论至少有招股书集团说明、官方披露、股权关系或两项独立硬线索支持；媒体名称映射必须保留链接和日期。

## 3. calculation_policy.md

所有模型开始前先冻结以下口径：

```markdown
## Terminal value
- 终值口径：发行价 / 发行市值 / 临时最近轮估值
- 终值日期：
- 股本口径：发行前 / 发行后 / 全面摊薄
- 汇率及日期：

## Financing and IRR
- 投资日期：首份协议日 / 逐笔实际付款日
- 同轮多协议处理：
- 不同系列/每股价格是否分开：
- 现金流项目：增资、买老股、卖老股、分红、发行时剩余持股终值

## Return terminology
- 已实现现金回款：
- 发行价口径持股市值：
- 发行价口径账面增值：
- 完整倍数 / IRR：

## Financial and operating data
- 币种、单位、会计准则：
- 实际/预测/未年化期间边界：
- 应收净额/总额、收入和周转天数口径：
```

规则：

- 发行价和发行市值已确定时，投资回报终值只能用发行价/发行市值；最近私募轮只展示融资定价路径。
- 没有逐笔付款流水时统一用首份投资协议日，不用全额付款日假设全部资金一次投入。
- “已实现收益”仅用于已出售股份、分红或其他真实现金回款；仍持股部分只能写发行价口径持股市值/账面增值。
- 同一轮不同系列或每股价格先分别计算，不能直接合并倍数。

## 4. disclosure_checklist.md

在目录、表格清单和全文关键词检索后，记录每项披露是否完整抽取：

| 模块 | 预期年份/期间 | 预期行数/表数 | 已提取 | 证据页码 | 报告位置 | slides 页码 | 状态/缺口 |
|---|---|---:|---:|---|---|---|---|

至少覆盖：

- 三张财务报表及附注、收入和成本分部、费用构成、working capital、期后结算。
- 全部经营 KPI 表；累计、期间、期末、月均、未年化口径必须分别标记。
- 每年五大客户和五大供应商逐行完整抽取；三年披露通常各应有 15 行。
- 行业排名、市场份额、竞对能力矩阵、Robotaxi/新业务等不同业务对应的行业格局表。
- 全部融资轮次、资本化表、历史股份转让、特殊付款、发行结果和解禁安排。
- 外部观点来源、日期、观点类型和内部数字校验。

状态只允许 `complete`、`not disclosed`、`needs verification`。不得用“已摘要”替代完整性检查。

## 融资多表勾稽

融资和股东回报必须把四类证据连成一条链：

1. Pre-IPO 投资表：轮次、协议日、融资额、投前/投后估值、每股价格。
2. 资本化表：截至最后可行日期的系列股份、当前持有人、最终持股数。
3. 历史股份转让表：老股买方、卖方、系列、股数、日期、对价。
4. 发行结果/配发结果：发行价、发行市值、发行后股本和终值日期。

对账输出至少包含：

- 当前持有人是否等于原始认购人；若不是，注明取得路径。
- 每轮新增股份与融资额是否匹配，估算机构投资额时是否按同轮各机构实际新增股份和每股价格计算。
- 老股买卖是否写入对应融资轮次及独立老股表；卖方现金回款和买方新成本是否进入完整回报现金流。
- 每一项机构成本、剩余持股市值和账面增值能否回指到具体系列、股数、每股价格与发行价。

## 交付前直接答案清单

报告和 slides 必须显式回答，不能只让读者查表：

- 哪一轮发行价口径倍数最高。
- 哪一轮/机构 IRR 最高，以及日期口径。
- 哪一轮整轮发行价口径账面增值最高。
- 哪一家投资机构发行价口径账面增值最高。
- 上市前最大外部投资人和最大外部财务投资机构分别是谁、持股多少。
- 已披露老股卖方累计获得多少现金回款；买方按发行价口径的倍数/账面增值是多少。
- 投资建议、目标价、对应市值、估值方法、风险情景和需要验证的触发条件。
