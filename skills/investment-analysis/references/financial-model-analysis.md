# 财务模型分析指南

## 先检查模型结构

- 列出工作表：输入假设、实际历史、收入build、成本费用、利润表、资产负债表、现金流量表、估值、情景、敏感性、输出页。
- 检查隐藏sheet、隐藏行列、命名区域、外部链接、手工硬编码、循环引用。
- 区分实际数、预算数、管理层预测、分析师预测和自动公式。
- 保留关键sheet和单元格引用。

二级市场模型同时保留五列身份和修订轨迹：`Reported / Company Guidance / Dated Consensus / Prior Estimate / Current or Our Estimate`。券商模型中的 `E`、`Est.` 或机构缩写（如 `GSe`）表示该机构估计，不是公司披露或市场一致预期；先读取表头、脚注和方法页确认定义。

## 券商研报与展示表反推

把研报视为“观点 + 模型 + 估值”的可审计产物，不把评级或目标价当作事实。逐张承重 exhibit 执行：

1. 记录表号/页码、期间、币种、单位、会计口径和数字身份。
2. 区分实际、公司指引、Consensus、券商预测、敏感性情景和我们的复算。
3. 反推公式及输入，标记该上行/下行是否已经进入 Base Case；不要把可选敏感性重复叠加到基准预测。
4. 沿 `经营驱动→Revenue/EBIT→EPS/FCF→估值→每股价值` 追踪，而不是只复述表格结论。
5. 为每个复算结果标记 `exact`、`approximate` 或 `unreconciled`；差异来自四舍五入、隐藏假设、口径错配还是缺失数据必须说明。

典型复算：

```text
分部Revenue/EBIT合计 ± 公司层/抵销 = 集团Revenue/EBIT
EBIT + 利息净额 + 其他非经营项目 - 税 = 归母净利润
归母净利润 ÷ 稀释股数 = EPS
CFO - cash capex = FCF
FCF + 净借款 ± 明确的股权持有人现金项 = FCFE
EV ± 净现金/净债务及其他调整 = Equity Value
Equity Value ÷ 全面摊薄股数 = Per-share Value
```

新增债务或融资不能凭“现金缺口”倒推成公司事实。先查债务附注、到期表、后续事项、公司指引和模型公式；券商为平衡现金而设置的债务插件应标为 `broker_estimate` 或 `calculation`，并列出金额、时点、利率、期限及是否循环融资。

## 核心审阅问题

1. 收入预测是否由真实驱动项支持：客户数、订单、价格、产能、利用率、留存、take rate、ARPU等。
2. 毛利率提升是否有机制：规模效应、产品mix、成本下降、自动化、采购议价，而不是简单线性改善。
3. 费用率下降是否合理：团队扩张、销售渠道、研发投入和管理半径是否支持。
4. 营运资金假设是否匹配商业模式：应收账期、库存周期、预收款、供应商账期。
5. CAPEX和折旧是否匹配产能、门店、设备、服务器或厂房扩张。
6. 融资需求是否被模型隐藏：现金余额是否为负，债务或股权融资是否自动补平。
7. 估值输出对哪些假设最敏感：收入增速、毛利率、WACC、退出倍数、永续增长率、折现期。
8. Prior→Current预测为什么改变：把Revenue、Margin、EPS、FCF和目标价修订桥到新增经营证据，而不是只展示新点值。
9. 目标价能否勾稽到目标市值、净债务、稀释股数和估值时点；分子与倍数是否口径匹配。

## 检查公式和完整性

- 横向公式是否一致，是否有断裂、硬编码或覆盖公式。
- 财务模型是否勾稽：净利润进入留存收益，折旧摊销加回现金流，CAPEX进入固定资产，债务利息联动。
- 资产负债表是否平衡，现金流是否解释现金变化。
- 历史期数据是否与原始财报一致。
- 单位和币种是否混用。
- 负数符号、税率、少数股东权益、租赁负债、股份支付是否处理正确。
- FCF、FCFE、净借款、租赁本金、并购和回购是否重复计算；期初现金到期末现金能否逐年滚动。
- Bull/Base/Bear是否联动经营、资本投入、融资成本、股本和估值，而不是只改倍数。

## 输出结构

```markdown
## 财务模型审阅:[公司名/模型名]

### 模型用途和覆盖范围
[模型用于融资、估值、预算、经营计划还是投后跟踪；覆盖期间和口径]

### 关键假设
- [收入、毛利、费用、营运资金、CAPEX、融资、估值假设]

### 公式和结构问题
- [硬编码、断链、循环引用、财务模型不平、外部链接、隐藏假设]

### 预测合理性
- [哪些假设可信，哪些过激，和历史/行业benchmark是否冲突]

### 敏感性和风险
- [最影响估值或现金流的3-5个变量]

### 需要追问管理层的问题
- [围绕模型弱点形成问题]
```

## 分析纪律

模型是观点，不是事实。不要只引用输出页，要回到假设和公式。对管理层模型尤其要问：“如果这三个核心假设打八折，公司是否还成立？”
