# 交易谈判核心理念

本文件是基金内部交易谈判的指导原则，所有条款分析和话术建议必须以此为底层逻辑。

---

## 第一原则：份额 > 估值

- **绝对重要的是份额，不是估值**。估值只是间接重要——因为「估值 × 份额 = 需要投多少钱」，在基金规模有限的约束下估值才相对重要
- **绝对回报金额 > 回报倍数**。倍数好看但金额才是真钱
- 综合决定回报空间的是 **TAM × 市场份额**，所以一直追求大机会——只有大 TAM 才能在高估值下仍然给出足够的回报倍数
- **实操含义**：在估值谈判中，如果份额能保住，估值可以有弹性；但如果高估值导致份额被压缩到失去意义，则宁可放弃交易

## 第二原则：经济权益条款 > 控制权条款

公司业务是创始人负责的，我们负责选好创始人、相信他。所以**影响经济权益的条款远比影响公司业务控制的条款重要**。

### 2.1 直接影响经济权益的条款（最高优先级）

这些条款会直接改变我们拿到的钱，**必须守住**：

| 条款 | 为什么重要 |
|------|----------|
| 反稀释 | 直接保护持股比例不被低价融资稀释 |
| ESOP 发放的否决权 | ESOP 扩池直接稀释投资人 |
| 后续融资 veto 权 | 防止不利条件的融资损害现有股东利益 |
| 修改本轮权益条款的否决权 | 防止后续轮次"重写"我们的权利 |

### 2.2 间接影响 — 公司发展好时保住份额（高优先级）

公司越成功，这些条款越重要——确保我们能跟着一起赚：

| 条款 | 为什么重要 |
|------|----------|
| 优先认购权（Pro-rata） | 后续融资时保持持股比例的唯一途径 |
| 优先购买权（ROFR） | 老股转让时不被边缘化 |

### 2.3 间接影响 — 公司发展不好时的保底（中优先级）

当退出回报不理想时，这些条款决定我们能拿回多少：

| 条款 | 为什么重要 |
|------|----------|
| 优先清算权 | 低价退出时先拿回本金+利息 |
| 回购权 | IPO 无望时的退出路径 |
| Drag-along | 确保可以推动退出，不被少数股东阻挠 |

### 条款优先级总结

```
必守底线：反稀释、ESOP veto、融资 veto、权益修改 veto
高优先级：优先认购、优先购买
中优先级：优先清算、回购、drag-along
可灵活的：业务层面的控制条款（年度预算审批、关键岗位任命等）
```

## 第三原则：MFN 是综合保底

- 要求**向前和向后的 MFN**（Most Favored Nation）
- 核心目的：防止公司通过 side letter 给其他投资人更好的条件而我们不知道
- 向前 MFN = 任何现有股东/同轮投资人的更优条款自动适用于我们
- 向后 MFN = 未来轮次投资人的更优条款自动适用于我们

## 第四原则：创始人限制服务于「选对人、绑住人」

我们最核心的投资逻辑是**选好创始人然后相信他**，所以创始人相关的限制条款本质上是保护这个前提：

| 条款 | 底层逻辑 |
|------|---------|
| 限制自由转股 | 创始人不应在公司没成功时就套现上岸——这跟投资人利益根本不一致 |
| 股权 Vesting | 确保创始人长期绑定 |
| 全职义务 | 确保创始人全身心投入 |
| 竞业限制 | 防止创始人精力和资源外泄 |

**沟通态度**：这些条款「适当去沟通」，不是强硬施加。要解释清楚为什么对双方都好。

## 第五原则：交易是共赢的艺术

> **在任何时刻，我们都不跟创始人是对立的，一定能找到共赢的点。**

- 交易是一种**艺术**更是一种**能力**
- 目标是 **make things happen**，不是因为双方是交易对手就真的对立
- 与法务、合伙人打好配合

### 实操要求

- **第一轮领投**：必须我们来起草交易文件
- **前序有投资人**：拿来前序文件 → 梳理清楚 → 了解创始人为什么那么设计 → 再提我们的诉求
- **Deal owner 的基本功**：所有条款学明白 → 领会背后的「为什么」→ 理清条款间的关系 → 抓大放小

## 基金核心决策人特别关注

以下是基金核心决策人特别在意的经济权益风险点：

1. **ESOP 发放导致的稀释** — 关注 ESOP 池的总量上限、发放审批机制、是否有向创始人发放的特别限制
2. **清算/回购中的 double dipping** — 确保优先清算权设计不会出现投资人既拿优先回报又按比例分配剩余（参与型优先 + 无 cap = double dipping 风险）
3. **Drag-along 的设计** — 确保拖售权能真正执行，关注触发门槛、最低估值限制、不配合的后果机制
