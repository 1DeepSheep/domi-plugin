# 行业/赛道扫描框架（sector mode）

目录：1. 通用维度 · 2. 一级分支 · 3. 二级分支 · 4. 分析动作 · 5. 报告结构模板

目标：在一个行业/主题里建立全局认知，定位机会与玩家，输出可被 company mode 复用的入围名单。先在 SKILL.md 第 0 步界定**赛道边界**（定义、地域、时间窗、上下游切面），再展开。

## 1. 通用维度（一级、二级都要覆盖）

| 维度 | 要回答的问题 |
|---|---|
| 赛道定义与边界 | 它包含什么、不包含什么、与相邻赛道的界线 |
| 市场规模与增长 | TAM/SAM、增速、生命周期阶段（萌芽/成长/成熟/衰退） |
| 价值链/产业链 | 上中下游环节、价值分布、卡脖子环节、利润池在哪 |
| 驱动因素 | 技术/政策/需求/成本/资本等驱动与抑制力 |
| 玩家地图 | 主要玩家分层（龙头/挑战者/新锐）、份额、定位 |
| 竞争结构 | 集中度、进入壁垒、议价格局（波特五力） |
| 商业模式谱系 | 该赛道主流变现方式与单位经济差异 |
| 关键趋势与拐点 | 正在发生的结构性变化、可能的拐点信号 |
| 投资逻辑与机会 | 钱往哪流、什么样的标的最受益、风险点 |

## 2. 一级分支（primary / 早期与成长赛道）

重「未来空间」「新机会」「谁会赢」，数据更靠推断与一手信号：

- **玩家地图以创业公司为主**：按融资轮次/方向分层，标注代表性创业公司与其差异化；可对重点公司转 company mode 深挖。
- **资本流向**：近 1-3 年该赛道融资事件、活跃机构、热门方向、估值水位 → 搜索 + 本地项目库比对。
- **技术/范式拐点**：是什么新技术或需求变化打开了这个赛道，时间窗多大。
- **TAM 自下而上**：用单位经济×渗透率推演，标注假设与置信度，别照搬卖方大数。
- **内部视角**：先查本地项目库和 Markdown 文档中该赛道已跟踪的项目与判断（`investment-mgmt`），避免重复并接续既有认知；只有用户明确要求才额外搜索飞书知识外挂。
- **可借** `product-deep-research` 对赛道内重点产品做深挖，`deep-research` 做多源主题研究。

## 3. 二级分支（secondary / 上市公司赛道）

重「格局」「景气」「估值水位」，数据密集可量化：

- **板块/指数视角**：赛道对应的上市公司集合、板块表现、景气位置 → `bigdata-com:sector-analysis` / `bigdata-com:sector-playbook` / `daloopa:industry`。
- **可比公司横评**：龙头与挑战者的增速/利润率/估值倍数横向对比 → `bigdata-com:peer-comparables` / `daloopa:comp-sheet`。
- **景气与催化**：行业周期位置、需求/价格/库存、政策与事件催化 → `bigdata-com:thematic-research` / `bigdata-com:catalyst-monitor`。
- **跨区域/跨板块对比**（如需）→ `bigdata-com:regional-comparison` / `bigdata-com:cross-sector`。
- **估值水位**：板块当前估值相对历史与可比的位置，隐含预期。
- **口径纪律**：统一可比口径、币种、报告期。

## 4. 分析动作（填完数据后必做）

1. **赛道一句话判断**：现在处在什么阶段、值不值得花时间、机会在哪一层。
2. **玩家地图**：分层列出代表玩家 + 一句话定位（表格化，便于落多维表格）。
3. **核心趋势 3-5 条** + 对应的受益/受损方。
4. **机会与风险两面**：哪类标的最受益、关键风险与证伪信号。
5. **入围名单**：值得转 company mode 深挖的标的清单（含初步理由）。
6. **结论与下一步**。

## 5. 报告结构模板（落飞书文档时用，可按需增删）

文档标题由文件名、飞书文档标题或项目主页承载，Markdown 正文直接从四级标题开始。主要板块固定使用 `####`；板块内确需分组时使用 `#####`，且仅在同一板块内的加粗话题标识超过 5 个时启用。正文不得使用 `#`、`##` 或 `###`。

```markdown
#### 一、摘要与判断
- 赛道一句话 ｜ 所处阶段 ｜ 核心机会 ｜ 入围名单

#### 二、赛道定义与边界
#### 三、市场规模与增长
#### 四、产业链与利润池
#### 五、驱动因素（驱动 vs 抑制）
#### 六、玩家地图（分层表格）
##### {玩家层级或技术路线；仅在本板块需分组时保留}
#### 七、竞争结构（五力 / 集中度）
#### 八、关键趋势与拐点
#### 九、投资逻辑：机会与风险两面
#### 十、入围深挖名单（→ company mode）
#### 十一、信源清单（含日期与置信度）
```

> 玩家地图与入围名单天然适合落本地资料库表格视图，便于后续筛选与转 company 研究；权威记录仍写入本地 SQLite，见 sources-and-output.md。
