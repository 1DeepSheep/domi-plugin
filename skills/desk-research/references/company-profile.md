# 公司/标的深度画像框架（company mode）

目录：0. 深度路由 · 1. 通用维度 · 2. 一级分支 · 3. 二级分支 · 4. 分析动作 · 5. 多标的横评 · 6. 报告结构模板

研究前先完成 SKILL.md 第 0 步的**标的指纹**锁定，再展开本框架。指纹固定记录「官网域名｜运营/法律实体｜品牌｜产品｜前身/兄弟产品｜各自当前状态｜一句话业务」，避免把同一主体下仍并行运营的产品误写成改名或关闭。把每个维度变成具体问题，作为取数的填空目标。

## 0. 深度路由

- **quick**：围绕用户点名的问题交付，但最低覆盖标的指纹、相关实体/前身、融资或财务口径、业务量级、关键商业动作、风险与 Claim Ledger。多标的请求优先用横评表，不扩写无关模块。
- **standard**：在 quick 基础上增加公司考古、Founder–Product Fit、客户—任务—付费工作流、完整定价、增长机制、竞争与关键假设。
- **deep**：在 standard 基础上增加长访谈全量抽取、历史页面/旧域名、产品产出全集、经营模型、独立反证、情景与估值，并执行多轮对抗校验。

## 1. 通用维度（一级、二级都要覆盖）

| 维度 | 要回答的问题 |
|---|---|
| 一句话定位 | 它是谁、为谁解决什么问题、凭什么 |
| 公司考古与转折 | 法律实体、品牌/产品版本、前身与兄弟产品、历次 pivot、哪次变化带来 PMF |
| 业务与商业模式 | 收入怎么来、完整定价架构、单位经济、关键客户/场景、可变成本与毛利压力 |
| 产品与技术 | 核心产品、差异化、技术壁垒、迭代节奏 |
| 客户工作流 | 使用者/决策者/付款者是谁，原任务如何完成，Aha moment、替代对象、留存与流失原因 |
| 增长与分发 | PLG/销售/平台/内容/KOL/社区/渠道分别有哪些可观察动作，何时开始，是否有结果归因 |
| 市场与需求 | 目标市场规模、增长驱动、需求真伪与刚性 |
| 竞争格局 | 主要对手、相对位置、护城河（网络效应/转换成本/规模/品牌/技术） |
| 团队与 Founder–Product Fit | 创始人/核心团队背景、过往战绩；哪些原则真实影响产品与商业决策；股权与治理 |
| 财务/经营 | 收入、增速、毛利、现金流、关键运营指标 |
| 风险 | 业务、市场、监管、执行、财务、关键人风险 |
| 估值与定价 | 当前估值/对价、隐含预期、对标 |

## 2. 一级分支（primary / 未上市项目）

数据稀疏，重一手信源与推断，**每条关键事实标注置信度**。额外深挖：

- **融资历史**：轮次、时间、金额、估值、投资方、用途；老股/回购情况。
- **公司考古**：把主体、旧域名、前身/兄弟产品、融资、产品发布、pivot、客户/收入/安装量节点、定价与渠道变化放在同一时间线上。每个转折回答「为什么改、结果是什么、是否真正带来 PMF」；模型/功能版本/独立产品不得混为一谈。
- **团队深描与 Founder–Product Fit**：创始人是否「这一个」项目的人（用其自述/Launch/融资公告绑定，勿靠搜索共现）；连续创业史、关键员工、组织规模与招聘信号。只抽取 2-4 条有原话且能映射到产品/商业动作的原则，按「原话 → 动作 → 结果或代价 → 真信仰还是融资叙事」分析。
- **客户—任务—付费工作流**：优先找 3-5 个真实客户/用户工作流，写清使用者、决策者、付款者、原流程、替代的人/软件/外包、Aha moment、持续付费和流失条件。无代表性样本时不得输出总体画像占比。
- **定价与商业模式**：保存带日期的完整公开价格梯度，区分按席位/工作区/用量/结果收费，检查免费额度、升级触发、Enterprise 的 DPA/SLA/onboarding、底层可变成本和定价锚点。公开菜单不能证明真实成交结构；没有底层数据时不得估收入流占比或付费客户数。
- **增长机制画布**：对 PLG/付费投放/KOL/内容/销售/平台分发/网络效应/社区/渠道分别记录「可观察动作｜开始时间｜结果/归因证据｜证据强度｜依赖与风险」。Creator Program、投资人名单、上架 Marketplace 等只证明机制存在；没有 attribution、UTM、用户调查、转化或 cohort 数据时不得宣称其贡献大小。可借 `product-deep-research` 做检索，但 desk-research 必须独立审计后再吸收。
- **业务量级证据**：收入、ARR/RR、客户、用户、安装量、团队和定价进入 Claim Ledger；逐项区分公司/产品/集团、注册/活跃/付费、总员工/研发团队及截至时间。
- **产出全集（技术/研究型标的 standard/deep 必做）**：盘点其全部公开产出——`GitHub org` 仓库（star/语言/日期）、`HuggingFace org` 模型与数据集、官网 SPA 用 CDP 渲染 /blog、/benchmarks 等索引页。带日期列全后再看产出「形状」（横向复制同一方法论 vs 真发散），**先盘点、后定性**，避免凭零散搜索把战略误判（取数与抓取细节见 sources-and-output.md §2/§6）。quick 仅抽取与问题相关的产出及采用度代理。
- **市场空间**：自下而上估 TAM/SAM/SOM，标注假设；避免直接搬行业报告大数。
- **退出逻辑**：潜在并购方/IPO 路径、可比退出案例、预期回报与周期。
- **关键风险**：单点依赖（大客户/单一渠道/关键人）、现金跑道、合规与数据来源、母子公司/关联方财务隔离。

## 3. 二级分支（secondary / 上市公司）

数据密集、可量化，偏好结构化金融数据源（daloopa / bigdata-com）。额外深挖：

- **财务建模**：三表关键科目、历史趋势、分部数据 → `daloopa:build-model` / `daloopa:tearsheet` / `daloopa:earnings`。
- **可比公司**：选对标集，比较增速/利润率/估值倍数（PE/EV-EBITDA/PS 等）→ `daloopa:comps` / `bigdata-com:peer-comparables`。
- **估值**：DCF 与相对估值，隐含预期拆解 → `daloopa:dcf` / `bigdata-com:valuation-snapshot`。
- **催化剂与预期差**：近期/中期催化剂、指引、市场一致预期 vs 自己判断 → `bigdata-com:catalyst-monitor` / `bigdata-com:variant-perception` / `daloopa:guidance-tracker`。
- **资本配置与治理**：分红/回购/并购/再投资、管理层激励、股东结构 → `daloopa:capital-allocation` / `bigdata-com:moat-governance-review`。
- **风险**：财报质量、监管、周期、杠杆 → `bigdata-com:risk-assessment` / `bigdata-com:earnings-quality-screen`。
- **口径纪律**：币种、单位、GAAP/Non-GAAP、报告期、是否最新季度。

## 4. 分析动作（填完数据后必做）

1. **核心发现 3-5 条**，每条按「事实 → 可能机制 → 投资含义 → 反证/替代解释」展开，并带支撑数据与来源。
2. **多空两面**：bull case（看好理由+成立前提）vs bear case（风险+触发条件）。
3. **关键假设**：投资逻辑成立依赖哪些假设，哪些已验证、哪些待验证。
4. **估值/对价判断**：当前定价隐含什么预期，是否合理（仅做逻辑梳理，不做买卖建议）。
5. **结论与下一步**：深入/访谈/放弃/进入估值或 IC。
6. **关键数字审计**：输出 Claim Ledger，保留原始披露术语；冲突指标解决后再进入摘要。无法解决时并列展示定义与时点，并按可核验下限、区间或 unresolved 表达，不强选单点。
7. **证据密度审计**：证据不足时缩短报告，不为凑数量补齐哲学、画像、KOL、竞品或情景。

## 5. 多标的 quick 横评

用户同时研究 2-5 个公司时，先分别完成标的指纹和 Claim Ledger，再用统一口径横评。推荐表头：

| 标的 | 主体/前身 | 产品与商业模式 | 已披露融资 | 业务量级（定义+时点） | 关键增长动作 | 证据状态 | 核心判断/待验证 |
|---|---|---|---|---|---|---|---|

表后只展开真正影响比较的差异、来源链和不可比项。安装量、注册用户、活跃客户、付费客户不得放进同一列直接排序；币种、报告期和产品/集团口径也必须统一或显式拆开。

## 6. 报告结构模板（落飞书文档时用，可按需增删）

```markdown
# {公司名} 深度画像（{primary/secondary} · {YYYY-MM-DD}）

## 一、摘要与结论
- 一句话定位 ｜ 核心结论 ｜ 下一步

## 二、标的指纹
- 官网/实体/股票代码 ｜ 业务一句话 ｜ 关联方说明

## 三、公司考古与关键转折   ← 一级重点；二级按需简化
## 四、产品与技术
## 五、客户—任务—付费工作流   ← 一级重点
## 六、业务模式、定价与单位经济
## 七、增长机制与分发
## 八、市场、竞争格局与护城河
## 九、团队、Founder–Product Fit 与治理
## 十、财务/经营   ← 二级：可比公司与估值表
## 十一、{融资历史 ｜ 催化剂与预期差}   ← 一级/二级各自填
## 十二、多空两面、关键假设与反证
## 十三、风险与下一步
## 十四、Claim Ledger（关键数字、定义、时点、证据状态）
## 十五、信源清单（按独立核实/公司口径/可观察动作/推算/假设分类）
```
