# 待办事项建议规则

## 优先级

- `P1`：7 天内的明确关键节点；S 级对象出现已核验重大新动态；已经承诺但临近截止的动作。
- `P2`：近 28 天新入库且值得约见；A/S 对象 60 天以上未联系；重点项目 45 天以上无跟进。
- `P3`：信息补全、较弱信号或没有明确截止日的维护动作。

不得仅因评级高就生成 P1。必须同时有时间、事件或承诺证据。

## 触发器

### 关键事件节点

真实日期字段落在未来 14 天内时生成，分类为 `key-milestone`。标题说明动作，不只复述日期。已过期但未完成的节点可生成一次 P1 补救事项。

### 近 28 天新入库

仅使用系统创建时间。项目或人物评级为 S/A，或有明确投资／关系价值证据时建议约见，分类为 `new-entry`；项目处于待交流、深度跟踪等明确需要沟通的阶段，人物处于待 Pitch、待认识、待引荐等明确关系阶段，也可作为价值证据。低质量空记录只生成数据补全事项或跳过。

同一对象已有项目跟踪或人脉跟进信号时，先比较下一动作：动作目的明显不同可以跨分类并存；最终都只是联系或约见时，合并理由并只保留一项。近 28 天对象优先归 `new-entry`，14 天内有真实截止日则优先归 `key-milestone`。不得用另一分类已有事项为理由压制全部新入库候选。

### 重要对象新动态

只接受已核验、带原始来源且与对象直接相关的行业事件。人物动态分类为 `relationship-follow-up`，项目动态分类为 `project-follow-up`。融资、职位变化、产品发布、重大合作和监管事件可以触发；泛行业新闻、转载和传闻不触发。

### 很久没见／没跟进

- S/A 人物最后联系超过 60 天，分类为 `relationship-follow-up`；
- S/A 项目最后跟进超过 45 天，分类为 `project-follow-up`；
- 没有历史联系日期时，只能说明“未填写”，不得说“很久没见”。

### 组合信号

新入库 + 关键节点、重点对象 + 新动态可提升一级，但 P1 仍受上限约束。

## 质量门

每项都必须回答：

1. 为什么是现在？
2. 用户下一步点按钮后具体做什么？
3. 来源对象是否可唯一定位？
4. 是否与现有开放、完成或忽略事项重复？

任一答案不明确就不生成，或降为 P3 的信息补全事项。

## 看板配额

从全部合格候选中选择最多 12 项：

1. 每个存在合格候选的分类先取最多 2 项；
2. 再按 P1、P2、P3、截止时间和证据强度填充剩余席位；
3. P1 总数不超过 4；
4. 其他分类仍有合格候选时，单一分类不超过 5；
5. 配额只影响本轮展示选择，不得把未入选候选伪装为 `done` 或 `ignored`。
