# 融资字段契约

项目资料库统一维护以下字段：

| 字段 | 类型 | 规则 |
|---|---|---|
| 历史融资 | Text | 按下述固定 Markdown 表格保存，按融资时间从晚到早排列 |
| 最新估值 | Number | 单位固定为“亿美元”，只写数字 |
| 投资机构 | MultiSelect | 只同步本文定义的八家关注机构 |

## 历史融资

固定格式：

```markdown
| 融资时间 | 融资轮次 | 投前估值 | 股东出资情况 | 投后估值 |
|---|---|---:|---|---:|
| 2026年3月 | B轮 | 5亿美元 | 合计融资5,000万美元，其中红杉3,000万美元、IDG 2,000万美元 | 5.5亿美元 |
| 2025年6月 | A轮 | 20亿元人民币 | 合计融资2亿元人民币，其中五源1.5亿元、蓝驰0.5亿元 | 22亿元人民币 |
```

1. 每轮必须依次写融资时间、融资轮次、投前估值、股东出资情况、投后估值；缺失项写 `—`，不得估算后冒充披露值。
2. 股东出资情况先写本轮合计融资额，再写各投资方及各自出资额；金额未知时只列已确认投资方并标注“出资额未披露”。
3. 保留原始币种并明确写“美元”或“人民币”；不要把历史轮次全部按当前汇率重写。
4. 老股转让、债权、可转债、SAFE、员工期权池或其他不直接进入公司的金额，在表格后单列说明；不得计入 `投前估值 + 本轮新增股权融资 = 投后估值`。
5. 投后估值缺失时，只有投前估值和本轮进入公司的新增股权融资额均明确、币种一致且不存在老股/债务混入时，才可计算；计算值必须标注“据披露金额计算”。
6. 同一轮存在冲突口径时同时保留两个版本、标注来源和冲突，最新估值留空，直到能够确定。
7. 仅一轮融资也使用相同表格，便于程序读取和后续追加。

## 最新估值

1. 选择时间最晚且已完成融资轮次的投后估值。只披露“本轮拟融资”或尚未交割的估值不写入。
2. 字段只写数值，单位固定为“亿美元”。例如投后估值 `5.5 亿美元` 写 `5.5`；投后估值 `5,000 万美元` 写 `0.5`。
3. 人民币估值按该轮估值日期最近可得的人民币兑美元汇率中间价换算；无法确定具体日期时，使用本次更新日最近可得的中国人民银行授权中国外汇交易中心公布的中间价。
4. 换算公式：

   ```text
   最新估值（亿美元） = 投后估值（亿元人民币） ÷ USD/CNY
   ```

5. 在“历史融资”表格后追加换算说明：`最新估值换算：人民币投后估值 ÷ USD/CNY；汇率 X，日期 YYYY-MM-DD，来源 中国人民银行/中国外汇交易中心。`
6. 默认保留三位小数；不得用未经注明的经验汇率。若币种不是美元或人民币且没有可靠汇率，最新估值留空并报告缺口。

## 投资机构

只关注以下 canonical 名称：

| Canonical 名称 | 可接受别名示例 |
|---|---|
| 红杉 | 红杉中国、HongShan、Sequoia China |
| 高瓴 | 高瓴资本、Hillhouse |
| IDG | IDG Capital、IDG资本 |
| 锦秋 | 锦秋基金 |
| Monolith/励思资本 | Monolith、励思资本、Lishi Capital |
| 五源 | 五源资本、5Y Capital |
| 蓝驰 | 蓝驰创投、BlueRun Ventures |
| 经纬 | 经纬中国、Matrix Partners China |

同步规则：

1. 只把融资轮次、股东名单或 Cap Table 中明确列为本项目出资方/股东的机构写入；履历、竞品、LP、接触、尽调、被拒或“正在谈”不算。
2. 当“历史融资”已覆盖全部已知轮次时，把 `投资机构` 替换为历史融资中命中的 canonical 名称交集：新增有证据的机构，移除没有证据或只在非投资语境出现的机构。
3. 当历史融资明显不完整时，只新增有证据的机构，不自动删除旧值；把待核实项报告给用户。
4. 不向该字段写入八家以外的机构。其他真实投资方仍保留在“历史融资”的股东出资情况中。
5. 每次新增、删除或保留机构时，在执行回执中列明对应轮次和证据片段，批量修改前先让用户复核。

## 写入与回读

1. 飞书模式写入前动态读取字段结构；字段缺失时创建 `历史融资` Text、`最新估值` Number 和所需投资机构选项。
2. 本地模式把相同内容写入 SQLite/Markdown 的 `financingHistory`、`latestValuationUsd100m` 和 `investors`。
3. 同一项目的三个字段应在同一次更新中提交，并同时刷新“最后更新时间”。
4. 写后回读并核对：历史融资最新一行、最新估值数值、投资机构集合和汇率说明互相一致。
