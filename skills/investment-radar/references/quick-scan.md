# Quick Scan 紧凑契约

用于 domi 客户端增量行业雷达。每次调度都在不改变频次、调用方 `followed_domains` 范围、证据门槛和归档质量的前提下执行完整轮次；本契约已包含 quick scan 所需字段、证据、评分、去重和输出规则，不再读取其他 Radar reference。

## 输入、后端与最小读取

调用方提供 `discovery_from / checked_after / checked_through`；`discovery_from` 默认 `max(checked_after-48h, checked_through-72h)`，缺失时最近 72 小时。重叠窗口用于发现迟发／迟索引事件，水位前发布但此前未收录的内容仍可新增；零新增不得扩大到 7／30 天，也不得跳过下一次调度。

按已锁定后端执行，绝不切换或双写：

- `local`：仅用 `<plugin-root>/scripts/domi-repo.cjs news list/get/upsert` 读写 SQLite + Markdown。
- `legacy_feishu_primary`：只读写已配置的既有行业动态 Base，禁止调用本地 `news` 命令；schema 或目标不可用时仅报告“搜索完成、归档未完成”。

每轮只读取一次：配置必需字段；本机 `priority-watchlist.md`；调用方 A/S 人物别名索引；当前事件字段和发现窗口的 `eventId/title/url/publishedAt` 索引；已启用用户信源的公开 URL、水位、领域、关键词、优先级。不得读取凭据、全量项目／人脉库、sourcing、taxonomy-sync 或其他 Skill。重点对象只用于匹配和消歧，不逐项搜索；缓存缺失／损坏或明确 schema 错误时才补读对应范围，不重启整轮。

项目监控集固定为评级 A/S 且“深度跟踪”；人物为评级 A 及以上，关系进展只作消歧。人物需姓名 + 组织／角色／项目等强信号；竞品或泛行业影响为 `related`，不能当直接命中。缓存过期继续使用并记录缺口，不自动全表回源。

## 关注范围与分类

- `followed_domains` 只能从以下七个规范领域选择：AI、半导体、智能出行、前沿科技、具身智能&机器人、消费、生物医药。列表可为空；为空时客户端必须在调用模型前暂停本轮。
- 本轮只搜索、归档和回传 `followed_domains` 中的领域；未关注领域即使发现候选也按 `out_of_scope` 拒绝，不得自行扩大范围。历史值“消费科技”只在读取和去重时归入“消费”，不得新写“消费科技”。
- 同时覆盖中英文融资、技术／产品、客户／订单／合作、政策、并购、财务、人事、机构动态和产业论点信号。
- 最多 12 个候选、8 个合格新增；停止扩展前为深度访谈／公开观点保留最多 2 个候选位。

直接使用以下 canonical 父子词表，不为分类读取完整项目库：

- AI：AI互动娱乐、AI社交、AI游戏、AI视频、AI图片、AI造物、AI心理、AI语音、AI效率工具、AI Coding、AI营销、AI金融、AI制药、AI医疗、AI招聘、AI健康、Agent、AI数据、模型层、AI基础设施、AI4S、世界模型、AI陪伴、AI搜索、AI 3D、AI教育、AI旅游。
- 半导体：存储、算力芯片、通信芯片、微处理器、模拟芯片、功率半导体、光电芯片、传感器、晶圆制造、封测、半导体设备、半导体材料、EDA&IP、无源器件。
- 智能出行：自动驾驶、OEM、动力电池、BMS、电机电驱、激光雷达、毫米波雷达、智能座舱、汽车芯片、汽车软件、充换电、线控底盘、热管理、新能源商用车。
- 前沿科技：卫星互联网、eVTOL、低空经济、商业航天、量子计算。
- 具身智能&机器人：工业机器人、协作机器人、物流仓储机器人、室内移动机器人、末端执行器、扫地机器人。
- 消费：食品饮料、美妆个护、服装鞋包、家居家电、消费品牌、零售、文娱、旅游、本地生活、可穿戴、AR/VR元宇宙、AI玩具、NAS／私有云。
- 生物医药：创新药、生物技术、医疗器械、诊断、生命科学工具、CXO、数字医疗。

识别到 canonical 子领域时用其唯一父级纠正领域；新闻可跨已关注领域，但每个子领域必须属于所选父级。不得把汽车芯片／自动驾驶、EDA&IP、工业机器人写到 AI。AI 是核心产品能力时可标 AI；药物、器械或诊断产品本身是核心时标生物医药；同时满足时新闻可双标。无法映射时只写已确认一级领域、子领域留空；quick scan 不创建 taxonomy 或沿用 orphan。

## 发现、核验与准入

1. 已关注领域宽搜并发，优先一次查询覆盖多个事件词；同时轻量读取与已关注范围相关或尚未分类的 RSS／网站／重点公众号／播客，先按 GUID／canonical URL 去重后合池。
2. 每轮固定执行中文专业科技媒体扫源，至少覆盖 `DeepTech 深科技`，并加入 `对话/访谈/专访/公开观点/趋势判断/roadmap/outlook/interview/prediction`。新闻稿不得提前挤掉预留的论点候选。
3. 宽搜发现重点对象直接信号后，才允许追加一次该对象定向检索；不得逐项目／逐人物搜索。
4. 必须打开最上游可访问原文，确认主体、事实／原始判断、发布时间、发布者和 URL。搜索／RSS／公众号摘要、数据库、播客标题只能发现，不能单独证明事实。无法访问正文记 `unavailable`，不得绕过登录、付费墙、robots 或读取浏览器 Cookie。
5. 只有范围相关、主体可识别、事件或论点具体、时间可确认且原文可访问时才采纳。纯转载、泛泛愿景、标题党、无事实／论点增量或未解决身份歧义不采纳。

访谈／演讲／公开观点需同时满足：人物由姓名 + 组织／角色唯一确认；原文、时间、语境可核验；含技术边界、明确时间表、量级、竞争格局、商业化或工作流等可证伪判断；摘要用“某人判断／预计／认为”明确归因，并分开已发生事实、判断和雷达含义。节目发布本身不是事件。

证据状态只能是：`独立核实`（监管／真正独立证据）、`公司／机构口径`（当事方声称）、`可观察动作`（产品／代码／招聘等）、`二手报道`（可靠媒体但未回溯充分一手）、`传闻／待核验`。多篇转载同一通稿仍是一条来源链；预测不能改写成事实。

## 事件、评分与归档

事件字段至少包括：`title/domains/subdomains/types/publishedAt/summary/investmentMeaning/url/source/companies/institutions/importance/confidence/evidenceStatus/worthFollowing/action/eventId/batch`；系统时间字段不得由模型覆盖。

事件 ID 为 `evt_v1_<SHA-256前20位>`，哈希语义是 `核心实体集合｜信息类型｜不可变事件键`。媒体、URL、标题、披露日期、金额、投资方、评分和批次不得入键。传闻转官宣、金额／投资方／客户／来源补充更新原事件；疑似同事件但无法确认时不自动合并或写入。

重要性 1–10：相关性、拐点、商业／采用信号、竞争／资本影响、规模／时效／可行动性各 0–2。可信度 1–10：来源 0–4、一手证据 0–2、独立验证 0–2、一致性 0–2；未解决冲突最高 5。默认值得关注为 `importance>=7 && confidence>=6`；高影响低可信只按“传闻／待核验”归档，不主动回传。A/S 身份只能提高相关性，不能提高可信度或替代准入门槛。

先用一次性内存索引去重，仅对模糊键精确查询。通过门槛的事件全部归档：0 条创建；1 条仅在事实、来源、金额、投资方、客户或分类有实质增量时更新；多条停止。写请求超时／未知先按 ID 回查，不能直接重放。全部写完后批量回读 ID、标题、发布时间、URL、评分、分类；本地主库还需验证 Markdown。单条失败不阻塞其他项。

`direct` 命中重点对象且为实质事件、可信度 >=6 时列为重点提醒，不受一般阈值；同一事件的项目／人物关系合并。不得修改项目／人物评级、状态、Notes、互动或更新时间，也不得把雷达新公司自动入库。

## 信源、播客与隐私

信源注册表及真实名称、关键词、水位只留本机，文件 `0600`；不得写插件、Git、诊断或事件正文。播客 quick scan 只发现公开元数据；无单集授权或 `autoProcess=true` 时不得下载、上传 PLAUD。已授权的下载／PLAUD 转写走独立后台队列，不占本轮预算；禁止私有 API、Cookie、付费／私密音频、HLS／DASH、DRM 绕过和本地／其他云 ASR 回退。

不保存大段受版权保护正文，只存结构化事实、短摘要和链接。不提供个性化买卖建议。

## 完成回执

每个拒绝候选只记一个主原因：`duplicate/not_event/unverified/unavailable/out_of_scope`。没有合格增量是正常完成；不得为凑数降门槛、扩大时间窗或创建“暂无新闻”。最后一行必须是：

```text
RADAR_RESULT {"added":N,"updated":N,"unchanged":N,"failed":N,"checked_through":"ISO-8601","discovery_from":"ISO-8601","candidates":N,"rejected":{"duplicate":N,"not_event":N,"unverified":N,"unavailable":N,"out_of_scope":N}}
```

依赖局部失败时记录对应领域／信源／归档缺口并继续其他项；事件库不可用时返回“搜索完成、归档未完成”。不得切换后端、无界重试或声称全网无遗漏。
